# Aquarium Espresso

![Aquarium Espresso](screenshot.jpg)



ESP32-S3 + ST7789 (320x240 横向き) で小さな熱帯魚水槽を再現します。

魚種は下記のとおり。ランダムで選ばれます。

グッピー

ネオンテトラ

ブラックテトラ

コリドラス

ヤマトヌマエビ

シルバーハチェット　※ほおっておくとジャンプしていなくなることがあります。

トランスルーセントグラスキャットフィッシュ

セルフィンモーリー

ミドリフグ

プラティ

アプロケイルス・リネアタス

クラウンローチ

ノソブランキス・ラコビー

（シークレット）

こちらから取れるアクションはありません。

この小さな世界を眺めるだけの癒しプログラムです。



## 配線

|ST7789|ESP32-S3|
|-|-|
|SCLK|GPIO12|
|MOSI|GPIO11|
|DC|GPIO9|
|CS|GPIO10|
|RST|3V3 直結 (使うなら `PIN\\\_TFT\\\_RST` を 8 に)|
|BLK|3V3 直結 (GPIO 制御するなら `PIN\\\_TFT\\\_BLK`)|

|microSD|ESP32-S3|
|-|-|
|SCLK|GPIO5|
|MISO|GPIO6|
|MOSI|GPIO7|
|CS|GPIO4|



## ビルド / 書き込み



Arduino IDEでビルド・書き込みしてください。

必要な設定は以下のとおりです。



PSRAM=OPI

FlashSize=16M

PartitionScheme=huge\_app



また、ライブラリとしてLovyanGFXをインストールしてください。



## オリジナルキャラを泳がせる



1024px x 1024px以内の透過PNGを作り、SD Cardにfish.pngという名前で保存すると、1～3匹のグッピーがオリジナルキャラに置き換わります。

特にオリジナルキャラが不要な場合は、SD Card Readerを接続しなくてもかまいません。



## オリジナル背景



SD Cardにbg.jpgという名前でJPEGを保存すると、画面いっぱいに縮小して背景になります（はみ出した部分は切り取られます）。プログレッシブJPEGには対応していません。
